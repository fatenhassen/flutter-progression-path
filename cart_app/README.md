# Task 6: Catalog + Cart App (Riverpod + Local JSON)

## Overview
A multi-screen Flutter app that displays a product catalog, allows adding items to a cart, and manages state using Riverpod.  
This task focuses on app-wide state management, navigation, and local persistence — all on a zero-cost stack.

## Features
- Product data loaded from local JSON file  
- Multi-screen navigation (Catalog → Product Detail → Cart → Checkout)  
- Search and filter by category  
- Add, update, and remove items from cart  
- Cart totals auto-calculated (subtotal, tax, total)  
- Persistent cart using SharedPreferences  
- Light and dark mode support  

### Bonus Features
- Pagination and infinite scrolling  
- Favorites list (saved locally)  
- Hero animations and smooth transitions  
  
 

## Technologies Used
- Flutter  
- Riverpod for state management  
- SharedPreferences for persistence  
- Local JSON for product data  
- Optional: go_router for navigation
